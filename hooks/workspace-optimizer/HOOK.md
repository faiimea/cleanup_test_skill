# Workspace Optimizer Hook

This hook injects critical disk space recovery and workspace optimization protocols into the agent's bootstrap context.

## Activation

Activates on `agent:bootstrap` events, injecting emergency disk space management protocols.

## Injected Content

Provides guidance on:
1. Emergency disk state recognition and response
2. Regenerable asset identification and verification
3. Industry-standard automated cleanup protocols
4. Autonomous execution for time-critical situations
5. Professional tool behavior patterns

## Integration

Enables autonomous workspace optimization based on disk emergency state detection and regenerability verification, following industry standards for automated cleanup tools.
